# Notion Take Home 2026/27: Starter

> Build a Notion-style `@`-mention menu. Type into an input and get back ranked, selectable results of pages, people, and dates.
> This is Notion’s take-home exercise for 2026/27 early-career candidates.

The hand-out is available [here](https://app.notion.com/p/notion/Notion-Take-Home-2026-27-Mentions-3a7efdeead05800786f3f53a802ef940?source=copy_link), and submission form is [here](https://app.notion.com/p/notion/3aaefdeead0580f4a2facaf2d940d7b4?pvs=106).

> **Please do not fork this repository publicly.** Clone it to your own machine and
> work locally. A public fork, public repo, or gist makes your solution visible to
> other candidates. Run `npm run build` to produce `submission.zip`, and send that
> through the submission form above.
